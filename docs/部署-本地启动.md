## 1. 起真服

目录：/workspace/墨圈猎场/server
默认端口：8787（可用环境变量 PORT）
默认击杀目标 K=30
正式联调不要挂 KILL_TARGET_K

```bash
cd /workspace/墨圈猎场/server
npm install
npm start
# ws://0.0.0.0:8787，PORT 可覆盖
# 冒烟（可选）：KILL_TARGET_K=5 npm run smoke（需已起服；正式联调不要挂 KILL_TARGET_K）
```

## 2. 起静态页

目录：/workspace/ink-hunt
静态端口：5173
打开：http://127.0.0.1:5173/battle.html
默认连 ws://127.0.0.1:8787；可用查询参数 ws= 覆盖

```bash
cd /workspace/ink-hunt
npx --yes serve -l 5173 .
# http://127.0.0.1:5173/battle.html
# ?ws=ws://host:8787 可覆盖
```
