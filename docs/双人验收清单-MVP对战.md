## 1. 验收项（对照 PRD §9）

### §1 两人自动匹配进入对局

| 项 | 内容 |
|---|---|
| 前置 | H5 可开；两端网络正常 |
| A 步骤 | 打开 H5 → 点开始/匹配 |
| B 步骤 | 打开同一 H5 → 点开始/匹配（15s 内） |
| 预期 | 两端进入同一对局；各自见自己地图；HUD 可见双方比分/击杀进度；匹配超时（约 15s）回大厅 |
| 冒烟 | 必测 |
| 回归 | 必测；再测：一端取消/超时、两端几乎同时点开始 |

### §2 本底怪行为与单机 Demo 无明显冲突

| 项 | 内容 |
|---|---|
| 对照 Demo | 开局约 26 只；类型 `drifter` / `swift` / `watcher`；视野内追击、视野外游荡；定时刷怪，场上上限约 180；圈杀清敌 |
| A/B 步骤 | 各进对局后不主动杀怪，观察 30–60s：刷怪节奏、类型分布、游荡→追击、画圈封杀 |
| 预期 | 与 Demo 同玩法手感；无「怪不刷 / 全图瞬满 / 类型全错 / 不追击」级冲突；**不要求像素级一致** |
| 冒烟 | 节点 2：观察刷怪+可圈杀即可 |
| 回归 | 必测；对照 Demo 同屏对比 1 局 |

### §3 塞敌：A 杀 1 → B 立刻 +1 同种

| 项 | 内容 |
|---|---|
| A 步骤 | 记住即将击杀的敌人类型（色/型）→ 击杀 1 只 |
| B 步骤 | 同步观察本图敌人数量与类型 |
| 预期 | B 场上**立刻**多 1 只**同种**；非「随机种」；延迟应体感即时（非数秒后） |
| 冒烟 | 节点 3 起必测（连续杀 3 只，核对 3 次） |
| 回归 | 必测；含 B 杀 → A 侧对称；连杀与冷却交叉见 §7 |

### §4 先到击杀目标 K 者胜并进结算

| 项 | 内容 |
|---|---|
| 配置 | 确认 K（默认 30；可用小 K 如 5 便于测） |
| A 步骤 | 将己方击杀推到 K（或配合小 K） |
| B 步骤 | 观察 HUD 与是否进入结算 |
| 预期 | 先到 K 的一方胜；两端进结算页；显示胜负与比分；落后方失败 |
| 冒烟 | 节点 3 可用小 K 测通路径 |
| 回归 | 必测默认 K；再测临界：A=K-1 与 B 同时冲分（以服务端权威为准） |

### §5 命尽 5s 自动复活；期间对手不暂停

| 项 | 内容 |
|---|---|
| 配置 | N 默认 3 |
| A 步骤 | 耗尽命数至「命尽」→ 停留复活倒计时界面，**不操作** |
| B 步骤 | A 倒计时期间继续击杀，尽量推高分 |
| 预期 | A：约 **5s** 后**自动免费复活**，次数不限；界面可有广告占位（见 §8）；B：**不暂停**，可继续打并可因此先到 K 获胜 |
| 冒烟 | 节点 3 起必测至少 1 次复活 |
| 回归 | 必测：复活≥2 次；复活途中对方胜；倒计时不可被跳过成「立刻活」（本版免费自动） |

### §6 升级三选一可触发，逻辑对齐单机

| 项 | 内容 |
|---|---|
| 对照 Demo | 经验够 → 暂停出 3 张卡；池含：轻步/宽容收笔/长锋画笔/厚纸/吸墨/粗笔/大构图/修补；点一张生效后继续 |
| A/B 步骤 | 各打到升级 → 确认弹出三选一 → 选一张 → 验证对应效果（如轻步移速变快） |
| 预期 | 可触发；每次 3 选项；选后生效且局内不卡死；选项集合/效果与 Demo **同池同逻辑**（对战增量外不另造一套） |
| 冒烟 | 节点 3：至少一端升 1 级选 1 次 |
| 回归 | 两端各升≥1 级；升级弹窗时对手不因此整局冻结（各打各图，仅本端暂停合理） |

### §7 反滚雪球：塞敌上限/冷却 + 落后补偿

| 项 | 内容 |
|---|---|
| 配置 | 冷却 0.3s；额外塞怪≤20；分差≥8 → 落后方移速+15%，分差清零后取消 |
| 步骤 A | 极速连杀，观察对 B 的塞敌是否受冷却/上限抑制 |
| 步骤 B | 故意落后≥8 分，测移速是否变快；追平后加成是否取消 |
| 预期 | 领先方**不能**无抑制把对面塞到无法操作；冷却/上限可配置且生效；落后至少一种补偿可感知 |
| 冒烟 | 节点 4：冷却可感或上限可触达其一即可 |
| 回归 | 冷却、上限、补偿三条都测；记录实际阈值（测后可改 TBD） |

### §8 结算页、复活界面广告占位（无真 SDK）

| 项 | 内容 |
|---|---|
| 步骤 | 触发复活界面 → 看占位并可点击走通；打完一局进结算 → 看占位并可点击走通 |
| 预期 | 两处占位**可见**；点击/展示路径可走完；**无**真实广告 SDK 请求；不阻断复活/回大厅 |
| 冒烟 | 节点 4 起 |
| 回归 | 必测两坑位；弱网点占位不卡死 |

### §9 输出可访问的 H5 地址

| 项 | 内容 |
|---|---|
| 步骤 | 用运维提供的公网地址，两台设备/两个浏览器打开 |
| 预期 | 外网可打开；能完成 §1 匹配进局；地址写入本清单「环境」并回报 PM |
| 冒烟 | 节点 5 交付时测通 |
| 回归 | 必测；记下 URL + 访问时间 |

## 附录 A · 双端冒烟最短路径（约 10 min）

1. A、B 打开 H5 → 匹配进同一局（§1）  
2. 双方确认本底怪在刷、可圈杀（§2）  
3. A 杀 1 只有特征的怪 → B 确认 +1 同种（§3）  
4. 任一方升级 → 三选一选一张（§6）  
5. A 故意耗命 → 看 5s 复活；期间 B 继续打（§5）  
6.（有则）连杀测冷却/上限；落后测移速（§7）  
7. 用小 K 或正常打完 → 结算页占位；复活界面占位（§4 §8）  
8. 记录 H5 地址（§9）

## 附录 C · Demo 对照速查（本底怪 / 三选一）

**本底怪（Demo）**

- 开局 `spawnEnemy`×26（近距离约 12）  
- 类型：`drifter`（红）、`swift`（橙）、`watcher`（紫）；随时间 `swift` 比例升  
- AI：`sight` 内 `alert` 追击，否则游荡  
- 刷怪：`spawnClock`，难度随时间升，场上 `<180` 才刷  
- 击杀：轨迹闭合且面积≥`minLoopArea` → 圈内清除  

**三选一（Demo 升级池）**

轻步(+12%速)｜宽容收笔(闭合+5)｜长锋画笔(轨迹+18%)｜厚纸(生命+25)｜吸墨(吸取+45)｜粗笔(轨迹粗+封圈无敌)｜大构图(最小面积-14%)｜修补(+45HP)  
每次随机抽 3 张，选 1 生效。

对战版应复用上述玩法逻辑；差异仅来自对战增量（匹配/塞敌/命数复活/反滚雪球/结算广告位）。
