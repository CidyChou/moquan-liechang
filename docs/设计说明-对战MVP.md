## 1. 大厅 / 匹配

### 1.1 信息架构

```
[大厅 Lobby]
  ├ 标题「墨圈猎场」
  ├ 副标题「1v1 对战 · 先到击杀目标」
  ├ 主按钮「开始匹配」
  └ （可选一行）说明：各打各的图 · 杀敌会塞怪给对手
       ↓ 点开始
[匹配中 Matching]  全屏半透明遮罩 + 中心卡
  ├ 文案「正在寻找对手…」
  ├ 旋转/脉动指示（纯 CSS，不依赖素材）
  ├ 倒计时「剩余 Xs」（默认 15，超时回大厅）
  └ 次按钮「取消」→ 回大厅
       ↓ 匹配成功
[对局准备 Ready]  短过渡 ≤1.5s
  ├ 「对战开始！」+ 双方昵称占位（「你」/「对手」即可）
  └ 自动进局内，无需再点
```

### 1.2 大厅关键标注

| 元素 | 规格 |
|---|---|
| 屏 | 全屏 `--bg`，居中内容区 `max-width: 420px` |
| 标题 | 28–32px / 800；副标 muted 14px |
| 主按钮 | 宽满内容区；高 48–52；底 `#f1d69f`；字 `#202526` 粗体（对齐 Demo `#restart`） |
| 次要说明 | 12–13px muted；可折叠，不挡主按钮 |
| 无其它入口 | 不做房间码、模式切换、设置页（本版） |

### 1.3 匹配中交互

1. 点「开始匹配」→ 立刻进 Matching，请求匹配。
2. 「取消」随时可点 → 取消请求 → Lobby。
3. 超时（15s）→ toast「暂时没人，稍后再试」→ Lobby。
4. 成功 → Ready 闪一下 → 进局内（Canvas 全屏）。

## 2. 局内 HUD

**原则**：只看自己地图；HUD 叠加在 Canvas 上；`pointer-events:none`（除升级卡 / 复活层可点区域）。

### 2.1 布局（桌面 / 大屏）

```
┌──────────────────────────────────────────────┐
│ [左上：本方状态]          [顶中：比分条]        │
│  等级 · 命数 · 本局击杀                        │
│  HP 条 · XP 条                                │
│                                               │
│                    (Canvas 地图)               │
│                                               │
│ [左下：摇杆·仅移动端]              [右下可选：] │
│                                   落后补偿 tip │
└──────────────────────────────────────────────┘
```

### 2.2 顶中「比分 / 击杀进度」★ 对战增量

一条横向比分条，固定顶中，宽 `min(420px, 92vw)`：

```
┌──────── 你 ────────┬──────── 对手 ────────┐
│  ●●●  12 / 30      │      18 / 30  ●●●    │  ← 命心 + 击杀/目标
│  ████████░░░░ 40%  │  ██████████░░ 60%    │  ← 进度条相对 K
└────────────────────┴──────────────────────┘
```

| 字段 | 说明 |
|---|---|
| 击杀分子 | 本方 / 对方当前击杀数（权威同步） |
| 分母 | 击杀目标 K（默认 30，可配置） |
| 进度条 | `kills / K`，双方各一条；领先方 accent，落后方偏灰或 danger 轻染 |
| 命心 | 开局 N（默认 3）；实心 = 剩余命；空心 = 已耗尽。命尽进复活时本方心全灭，复活后回满 N |
| 分差提示 | 可选：分差 ≥8 时在比分条下出一条小 tip「落后补偿生效 · 移速+15%」（仅落后方可见） |

**不要**：对手画面、小地图敌方实体、聊天。

### 2.3 左上「本方状态」（继承 Demo，微调）

保留 Demo 结构，改动：

| Demo | 对战版 |
|---|---|
| 等级 / 击杀 / 时间 | **等级**保留；**本局击杀**可与顶中重复则左上可只留等级+时间，或击杀改「本局」小号；建议：左上 = 等级 + 时间；击杀以顶中为准，避免双处大数字打架 |
| 生命条（连续 HP） | **保留**（单机是连续血量）；另用顶中「命心」表示对战命数 N。文案区分：条旁写「生命」，心写「命」 |
| 经验条 | 保留，升级触发三选一 |

右上 Demo 操作 hint：对战局内默认隐藏（或首次局内一次后不再显示）。

### 2.4 瞬态 Toast（顶中偏下）

沿用 Demo `#message`：封圈击杀、塞敌反馈、强化名等。  
对战增量建议文案：

| 事件 | 文案 |
|---|---|
| 我方击杀并成功塞敌 | `封圈 · N 杀`（同 Demo）+ 可选弱提示 `已塞给对手` |
| 对手杀怪塞到我方 | `对手塞来 · {怪名/同种}`（勿刷屏：合并 0.8s 内多次为「对手塞来 ×N」） |
| 落后补偿触发/取消 | `移速补偿生效` / `补偿结束` |

## 3. 升级三选一

对齐 Demo `#levelup`，局内全屏遮罩。

### 3.1 结构

```
遮罩 rgba(5,9,10,.58) + blur
└ modal max 760px
   ├ 标题「选择一次强化」
   ├ 说明「每次升级只选一个」（muted）
   └ 三列卡片（移动端改单列）
      每卡：icon · 名 · 描述；整卡可点
```

### 3.2 交互规则

1. 升级触发 → **仅本方暂停**（本方 `paused`）；**对手不暂停**（PRD：各打各的）。
2. 选项池与 Demo `upgrades` 一致（轻步 / 宽容收笔 / 长锋画笔 / 厚纸 / 吸墨 / 粗笔 / 大构图 / 修补），随机抽 3。
3. 点选一张 → 应用 → 关层 → 本方恢复；toast「{名} 已强化」。
4. **不可点遮罩关闭**；必须三选一（避免卡死进度）。若后续要超时自动选，标 TBD，本版不做。
5. 复活倒计时中若同时升级：复活层优先；复活完成后再弹三选一（排队一个）。

### 3.3 卡片规格

- 最小高约 152px（桌面）；hover：上移 3px + accent 边。
- 触控热区整卡；无二次确认。

## 4. 命尽 · 5s 复活（含广告占位）

### 4.1 触发

本方当前命耗尽（连续 HP≤0 且消耗 1 命后命数=0，或按后端权威「命尽」事件）→ 进入复活层。  
期间：**本方不可操作**；**对手继续打**；本方 Canvas 可继续渲染但角色消失/灰态。

### 4.2 结构

```
全屏遮罩（可略深于升级层）
└ 中心卡 max-width: 520px，居中
   ├ 标题「画笔折断了」
   ├ 主文案「5 秒后自动复活」
   ├ 大号倒计时「5」→「4」…「1」（danger 色，约 64–80px）
   ├ 【广告占位区】见下
   └ 底注「免费复活 · 不限次数 · 对手仍在进攻」muted
```

### 4.3 广告占位（不接 SDK）

| 项 | 规格 |
|---|---|
| 区域 id | `#adRevivePlaceholder` |
| 尺寸 | 宽 100% 卡内；高 **建议 120px**（移动）/ **160px**（桌面）；灰底 `rgba(255,255,255,.06)` + 虚线边 |
| 内文 | 居中「广告位 · 复活」+ 小号「本版仅占位」 |
| 点击 | **可点**：toast「广告占位（未接 SDK）」或空回调；路径走通即可 |
| 倒计时 | **不因点击广告暂停**；满 5s **自动免费复活**（PRD） |

### 4.4 时序

```
命尽 → 显示层 & countdown=5
每秒刷新数字
t=0 → 关层 → 本方以满命 N、满/约定 HP 复活 → 短暂无敌建议 0.55s（对齐 Demo invuln）
若此期间对方已先到 K → 直接进结算（胜负以服务端为准），复活层被结算替换
```

### 4.5 注意

- 倒计时用服务端权威剩余时间更稳；前端可本地预显，以校正为准。
- 不出现「看广告立刻复活」按钮（后续才做）。

## 5. 结算页（含广告占位）

### 5.1 触发

任一方击杀先到 K；或断线判负等 → 双方进结算（全屏层，盖住局内）。

### 5.2 结构

```
遮罩 + modal max-width: 520px，居中 text-align center
├ 结果标题：胜利「猎场封圈」/ 失败「墨尽人散」（可再议文案；忌与 Demo「画笔折断了」复活文案混淆）
├ 副文：你 12 : 30 对手   或「你 30 · 对手 22」
├ 一行数据：用时 · 本方等级 · 本方击杀
├ 【广告占位区】#adResultPlaceholder
├ 主按钮「再来一局」→ 回大厅并自动开始匹配（或只回大厅；推荐：回大厅）
└ 次按钮「返回大厅」→ Lobby（若主按钮已是回大厅，可只留一个）
```

**推荐按钮**：只留一个主按钮「返回大厅」（避免首版分叉）；需要连战再加「再来一局」。

### 5.3 广告占位

| 项 | 规格 |
|---|---|
| id | `#adResultPlaceholder` |
| 尺寸 | 同复活：宽满卡；高 120–160px |
| 样式 | 虚线框 +「广告位 · 结算」 |
| 点击 | 同复活：走通、无 SDK |

### 5.4 胜负视觉

| 结果 | 标题色 | 其它 |
|---|---|---|
| 胜 | accent / 暖金 | 可轻微粒子，非必须 |
| 负 | muted 或 danger 软化 | 勿大红刺眼全屏 |

## 6. 页面 / 状态机（给前端）

```
Lobby → Matching → Ready → InGame
InGame → LevelUp（本方暂停叠层）→ InGame
InGame → Revive（本方锁操作）→ InGame
InGame → Result → Lobby
Matching → Lobby（取消/超时）
任意 InGame 子层被 Result 抢占时，先关子层再开 Result
```

Z-index 建议：Canvas `0` · HUD `4` · Toast `5` · 摇杆 `6` · LevelUp `10` · Revive `11` · Result `12` · 系统 toast `13`。

## 8. 验收对照（设计侧）

- [ ] 大厅仅「开始匹配」，无房间码 / 观战入口

- [ ] 结算有胜负与广告占位；可回大厅  
- [ ] 真广告 SDK：无
